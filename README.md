# 寺田通雄君を偲んで｜人生の履歴書

男性A07「夜の回想録」、配色01「オブシディアン・黒と銀」を使った、1ページ・3篇の記念サイトです。

本文は従来の3ページから省略せず収録しています。32段落・19小見出し・3篇の題と副題・写真説明・共通の末尾説明を元の文章と照合しました。本文中の「この3ページ」という表現も原文のままです。ページ番号や前後のページ操作は、同じページ内の3篇への移動に替えました。

写真2枚は提供画像のファイルを変更していません。人物の写真は加工画像であり、実際の同時撮影写真ではないことを説明しています。拡大ボタンで大きく表示できます。A07の飾りは本文とは別の装飾として配置しています。

- 標準の本文18px、拡大20px・22px。見出しは24〜28pxを基本に、表紙は大きな題字を使います。
- 上の「文字の大きさ・印刷」で文字拡大、動きの停止、A4印刷ができます。
- 上部の3篇のメニューから、その篇へ移動できます。
- 以前のmemories.html、message.htmlは、新しい1ページの第二篇・第三篇へ移動します。
- 検索除外のnoindexを保持しています。

静的なHTML・CSS・JavaScriptです。編集正本はindex.html、css/a07-color01.css、css/memorial-a07.css、js/memorial.js。ビルドや外部サービスへのデータ送信は必要ありません。元の公開版はGitの履歴にも残っています。

確認：元の文章との照合、画像2枚のファイル一致、PCでの表示、375pxの確認枠での22px表示、文字拡大、写真拡大、旧URLの移動。スマートフォン実機とプリンター実機は未確認です。
